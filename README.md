## 📌 About the Project

**MERN Class Demo** is a practical learning repository containing multiple web development exercises and applications created while exploring frontend development, backend development, REST APIs, MVC architecture, JavaScript, and the MERN stack.

Instead of being a single application, this repository acts as a **development playground and learning portfolio**, bringing together different concepts and implementations in one place.

The repository demonstrates the progression from basic web technologies to backend APIs and full-stack application development.

---

## ✨ What's Inside?

The repository contains several learning modules and projects:

### 🌐 Frontend & Web Technologies

- HTML-based web pages
- CSS styling and layouts
- JavaScript programming
- jQuery-based exercises
- Interactive web components
- Form handling
- Client-side functionality

### ⚙️ Backend Development

- Node.js development
- Express.js applications
- Backend API implementation
- REST API concepts
- Request and response handling
- Server-side JavaScript

### 🔌 REST APIs & MVC

The repository includes implementations demonstrating:

- RESTful API architecture
- MVC design pattern
- API routing
- Controllers
- Server-side logic
- CRUD operations
- Backend/frontend communication

### 📚 Online Book Management

The repository also contains an **Online Book Management / Online Book Store** implementation demonstrating concepts such as:

- Book management
- Web-based user interfaces
- Backend integration
- Application structure
- Data handling

### 🧪 Practice & Experiments

The repository contains smaller programs and experiments created to understand:

- JavaScript fundamentals
- C programming
- Web development concepts
- API integration
- Frontend/backend interaction
- Full-stack development workflows
